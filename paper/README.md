# From Message Authorization to Effect Binding: arXiv Preprint

LaTeX source for *From Message Authorization to Effect Binding: Conditions,
Counterexamples, and a Conformance Harness*.

**Status: skeleton for co-author review — not yet submitted.** Sections 1–6 and
8 are written. Section 7, "Does It Actually Work?", is a placeholder marked in
the source with `% ===== PLACEHOLDER: results not yet written up =====`: the
tables are wired to `../results/` and render, but the prose that reads them is
not written.

**Prose style.** The plain, concrete, direct register of the sibling paper:
examples before abstractions, ordinary words for technical things, and explicit
statements of what is *not* known or claimed. Section titles are plain
declaratives ("The Problem", "Does It Actually Work?", "What We Still Don't
Know"). The paper opens with the retry ambiguity rather than the parser
differential, because a case where every component behaves correctly and the
composition is still wrong is the clearest evidence that the gap is structural.

**No number in this paper is typed by hand.** Everything in Section 7 arrives
from `../results/`, generated by `../scripts/regen-results.sh` and regenerated
in CI, which fails on a diff. If a figure needs to change, change the code.

## Build

```bash
cd paper
tectonic main.tex
```

Output: `main.pdf`.

`-Z shell-escape` is *not* required. The sibling paper needs it for `minted`,
which shells out to pygments; this preamble deliberately omits `minted` and
uses `listings` instead, so the CI build has no Python dependency. Passing the
flag anyway is harmless.

## Before Submission — Required Steps

1. **Co-author consent.** The author list is deliberately short at this stage:
   one author, rather than the sibling paper's list inherited wholesale. Add
   co-authors only on explicit consent and substantive contribution. The
   title-page footnote states this.

2. **Citation verification.** Every entry in `references.bib` is a primary
   source and each should be confirmed against it before submission —
   particularly the page ranges on Saltzer & Schroeder (1975) and Dennis &
   Van Horn (1966), and the report number on Anderson (1972). The Kaminsky,
   Linhart and Kettle entries are white papers and conference talks rather
   than refereed articles, and are cited as such.

3. **Numbers refresh.** Run `../scripts/regen-results.sh` and rebuild. CI
   diff-gates every generated file except `results/differential-host.json`,
   which is a measurement of the machine that produced it.

4. **The banner check.** *This item has no counterpart in the sibling
   checklist and this paper needs it.* Confirm that no table or figure derived
   from `../survey/desk-study.toml` appears without its banner, and that the
   word "measured" appears nowhere near it. The banner is generated as the
   table's `\caption`, so `\input`-ing the table carries it automatically —
   the failure mode to check for is someone copying rows out of the generated
   file into a hand-written table.

5. **The corrected split.** Section 6 reports 4 / 7 / 13 against the desk
   study's published 4 / 6 / 14. Confirm the correction is still stated as a
   finding about the method rather than silently applied, and that the
   sentence declining to treat 54% as a population estimate survives editing.

6. **arXiv metadata.** Suggested categories: cs.CR (primary), cs.SE and cs.DC
   (secondary). Licence: Apache-2.0, matching the implementation, which arXiv
   accepts as a submission licence.
